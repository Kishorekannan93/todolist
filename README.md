# 📖 Overview

The **ToDo List** application is a lightweight task management tool designed to help users efficiently organize and manage their daily activities.

Built using core web technologies, the project demonstrates JavaScript DOM manipulation, event handling, and dynamic UI updates while providing a clean and responsive user experience.

---

# 🎯 Project Objective

The objective of this project is to build an interactive task management application that enables users to:

- Create tasks
- Organize daily activities
- Improve productivity
- Practice JavaScript fundamentals
- Understand DOM manipulation

# 🚀 How It Works

1. Enter a task in the input field.
2. Click the **Add** button.
3. The task is added to the list instantly.
4. Delete completed or unwanted tasks with a single click.
5. Manage your daily activities efficiently.
